# Curse aeriene

Listă dublu înlănțuită cu curse aeriene citite din fișier.

## Funcționalități

- citirea curselor din `Fisier.txt` și inserarea în listă
- traversarea în ambele sensuri
- calculul întârzierii medii
- afișarea curselor cu întârziere peste un prag dat
- dezalocarea memoriei

## Structura de date

`CursaAeriana`: id, destinație, data plecării, minute de întârziere, pasageri înregistrați.

## Rulare

Se deschide `CurseAeriene.sln` în Visual Studio. Fișierul `Fisier.txt` trebuie să fie în directorul de lucru.
